# Security and private-data policy

This is a public code repository. Do not use it to distribute controlled,
confidential, or unpublished source data.

- Do not commit annotations, images, masks, expression matrices, Xenium output
  bundles, model weights, credentials, or private storage URLs.
- Keep real path configurations outside the repository. The committed YAML
  files are placeholders only.
- Report suspected credential or data exposure privately to the repository
  owner. Do not open a public issue containing sensitive paths or data.
